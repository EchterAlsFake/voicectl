# voicectl DMS Plugin

A native DankMaterialShell (Quickshell) plugin for `voicectl`.

## Features
- **Status Bar Widget**: Shows live microphone status icon and operating mode (`PRESENT`, `VOICE`, `OFF`).
- **Interactive Controls**:
  - **Left Click**: Cycles mode (`Presentation` ↔ `Normal` ↔ `Off`).
  - **Right Click**: Opens popout with live metrics (Inference Device: NPU, last command, recognition latency) and quick mode buttons.
- **Control Center Integration**: Provides a tile in the DMS Control Center.
- **Settings**: Toggle label visibility and configure background status polling interval.
